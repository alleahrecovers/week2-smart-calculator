# My GitHub Copilot Experience

## What Worked Well

1. Copilot helped me create the basic calculator function and showed me how to use if and elif statements for different math operations.

2. It helped me understand how a brute-force search works by generating a function that tests different values of x and keeps track of the closest answer.

3. Copilot helped me create the equation solver and the search visualization, which made it easier to see how the program searches for a solution.

4. It also helped me build the interactive menu that connects all the different functions together.

## Challenges

1. One challenge I had was indentation. Some of the suggested code did not line up correctly, which caused Python errors. I had to correct the indentation to make the program work.

2. Another challenge was making sure the function names matched. One suggestion used a different name for the basic calculator function, which would have caused an error when selecting that menu option.

3. I also had some trouble getting everything set up in VS Code, especially GitHub Copilot and the terminal.

## My Judgment

One thing I learned is that I should not automatically accept everything Copilot suggests. I had to review the code and make corrections when something did not match my existing functions or caused errors.

I also learned that testing the code is important. For example, I tested the search function using the equation 2x - 10 = 0 and confirmed that it returned x = 5 with an error of 0.0.

Copilot was helpful, but I still needed to understand the code, check its suggestions, and make sure everything worked correctly.
